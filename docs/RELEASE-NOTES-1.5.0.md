# ProfileDock 1.5.0

## Your layout

- Choose your own columns and rows, from 1 to 12 each, directly in the notch grid menu or under Settings → Appearance.
- Set columns and rows independently, or choose Automatic.
- Apps and terminals paginate independently. Tall pages scroll; narrower displays adapt the column count to keep tiles readable.
- Hide the Terminals and Usage Insights sections independently, including their headings and reserved space. Your connection settings and expansion choices are kept.
- Drag profile handles to reorder. A floating preview follows the pointer, with a faded source and insertion indicator. Escape or dropping outside cancels. Reduced Motion is respected.

## Claude and coding terminals

- Add your existing Claude Desktop app. Connecting Claude Code activity recognizes the running or installed app automatically.
- Open Terminal.app tabs running foreground Claude Code or Codex appear automatically. Closed sessions, idle shells and background-only agents stay out of the strip.
- Circular corner logos identify Claude Code and Codex terminals. Refresh discovery from the strip or connector settings.
- Separate Codex, Claude Code and Terminal connector controls make connection and discovery status visible.
- Add Profile offers installed Codex and ChatGPT applications directly, with a browse option.

## Local activity and history

Claude Code hooks report local working, waiting and completed states and available subscription counters. Existing hooks and custom status lines are preserved. Local Code history, context permissions and usage insights use the existing ProfileDock controls. Start a new Claude Code session after connecting to receive activity updates.

Claude Chat, Cowork, remote/cloud-only activity, and per-tab Codex CLI activity/usage are not covered. Other terminal apps and SSH sessions are not included. See [Claude and Terminal setup and provider differences](CLAUDE-TERMINAL.md).

Existing profiles, sign-ins and preferences are preserved. Requires macOS 14 or later on Apple Silicon.
